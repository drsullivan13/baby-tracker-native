# Baby moon artwork

Generated with the built-in image-generation tool; no model named Imagine 2.5 was selectable. Original: `baby-moon-original.png`. App icon: `../Assets.xcassets/AppIcon.appiconset/AppIcon.png`. Onboarding asset: `../Assets.xcassets/BabyLogo.imageset/BabyLogo.png`.

The original is retained; production assets are resized to 1024×1024 with opaque backgrounds. iOS applies its own outer icon mask and user-selected tint.

## Generation prompt

Use case: logo-brand. Create a delightful premium iOS app icon for a private baby tracker. One original memorable symbol: a peaceful sleeping baby face nestled inside a soft crescent moon / swaddle, with one small warm star. Cozy playful rounded sculptural illustration, crisp bold silhouette, sophisticated minimal detail, gentle dimensional shading, not photorealistic. App palette: deep midnight navy background, luminous teal swaddle, warm cream face and crescent, coral cheek, small golden star. Full-color opaque square 1024x1024 artwork, fills canvas edge to edge with navy background; centered large mark occupying about 75 percent. Must read clearly at small phone icon size and in grayscale/tinted mode through strong luminance contrast. No text, letters, borders, rounded outer corners, mockup, device, watermark or extra objects. This is the actual final icon asset, not a presentation board.
